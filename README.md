# Which Article is Longer?

`index.html`をブラウザで開いて遊べます。インターネット接続が必要です。ビルドや依存パッケージのインストールは不要です。

英語の記事名を2つ入力し、サジェスト候補をそれぞれ選んで「この2記事で予想する」を押してください。「ランダム出題」でも遊べます。長いと思うカードを選ぶと、両記事のByte数と正誤が表示されます。

比較対象は英語版WikipediaのMediaWiki API `prop=info` が返す記事ソースの`length`です。脚注・出典・Wiki記法を含み、表示本文の文字数やHTMLファイルの容量とは異なります。出題時点の値で判定します。

同じByte数の場合は引き分けで、成績は変わりません。ページを再読み込みすると成績がリセットされます。

候補選択は上下矢印とEnter、候補を閉じる操作はEscapeに対応しています。通信エラー時は入力し直すか、出題ボタンを再度押してください。

Google Fontsが読み込めない場合は標準フォントを使います。Wikipedia非公式のゲームです。

## 検証

Node.jsがある場合、`node --test tests/core.test.js`で判定と通信のテストを実行できます。
